# 📚 Granthokutir - AI-Powered Digital Library Management System

## 📖 About The Project

**Granthokutir** (গ্রন্থকুটির) is a modern, AI-powered digital library management system built with PHP and MySQL. It provides a complete solution for educational institutions to digitize their library operations, offering seamless book management, secure online payments, AI-assisted learning, and comprehensive analytics.

### 🎯 Problem Statement

Traditional library management systems suffer from:
- Manual record keeping and paperwork
- Time-consuming borrowing/returning processes
- Risk of data loss and human errors
- No support for digital books or online access
- Lack of AI-powered learning features

### 💡 Our Solution

Granthokutir solves these problems by providing:
- Fully automated digital library management
- AI-powered book summaries and MCQ generation
- Secure online payment integration (SSLCommerz)
- Role-based access for Admins, Moderators, and Students
- Real-time analytics and reporting
- Digital book reading with PDF.js

## ✨ Features

### 👨‍💼 Admin Panel

| Feature | Description |
|---------|-------------|
| **Dashboard** | Overview of revenue, books, users, and support tickets |
| **Book Management** | Add, edit, delete books with PDF & cover upload |
| **User Management** | Manage students, ban/unban users with reasons |
| **Moderator Management** | Create moderators and assign granular permissions |
| **Review Moderation** | Monitor and delete inappropriate reviews |
| **Support System** | Reply to user support tickets |
| **Revenue Analytics** | Weekly & monthly revenue charts with Chart.js |
| **Sales History** | Track book rentals and stone purchases |
| **Profile Management** | Update admin profile with picture |

### 🎓 Student Panel

| Feature | Description |
|---------|-------------|
| **Registration/Login** | Secure authentication with password hashing |
| **OTP Password Recovery** | Email-based 6-digit OTP verification |
| **Book Browsing** | Search and filter books by category |
| **Free Borrowing** | Borrow free books for specified durations |
| **Paid Purchase** | Buy premium books via SSLCommerz |
| **Dynamic Rental Days** | Custom rental durations (editable by admin) |
| **PDF Reader** | Read books with PDF.js and save bookmarks |
| **AI Assistant** | Get book summaries and MCQ generation |
| **Audio Reading** | Text-to-Speech with Bengali voice support |
| **Night Mode** | Adjustable brightness for comfortable reading |
| **Reviews** | Rate and review books |
| **Support Tickets** | Submit and track support requests |
| **Buy Stones** | Purchase virtual currency for AI features |
| **Profile Management** | Update personal information |

### 🛡️ Moderator Panel

| Feature | Description |
|---------|-------------|
| **Dashboard** | Overview of pending tasks and recent activity |
| **Support Tickets** | Reply to user support requests |
| **Review Management** | Monitor and delete inappropriate reviews |
| **Book Management** | Add/edit/delete books (with permission) |
| **Activity Log** | Track all moderation actions |
| **Profile Management** | Update moderator information |

### 🤖 AI-Powered Features

- **Google Gemini Integration** - Book summaries, MCQs, and Q&A
- **Context-Aware Responses** - Uses book's admin summary as context
- **Stone-Based Economy** - 2 stones per AI query
- **Chat History** - All conversations saved for reference
